# Música MP3

Sube aquí tus archivos `.mp3` desde GitHub.

Después dime el nombre exacto de cada archivo y el título/artista que quieres mostrar para añadirlo a `music/playlist.json`.

Ejemplo de entrada en la lista:
```json
{ "title": "Mi canción", "artist": "Artista", "file": "mi-cancion.mp3" }
```
